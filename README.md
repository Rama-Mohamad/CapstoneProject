#  Smart Access Control System Using Dynamic OTP Codes

##  Project Overview
The **Smart Access Control System Using Dynamic OTP Codes** is a secure and intelligent gate-entry solution designed for university campuses and controlled facilities.  
Instead of relying on traditional RFID or smart cards, the system uses **dynamic one-time passcodes (OTPs)** generated through a mobile application.  
Each OTP changes automatically within a fixed time interval ( every 30 seconds), ensuring enhanced security and contactless access.  



## Expected Outcomes
- Faster and more reliable gate operations.  
- Increased safety and reduced need for manual guards.  
- Scalable system adaptable for universities, companies, and residential complexes.
- Enable Real-Time Monitoring – Record every event and access attempt .  
- rovide Manual Override for Security Personnel – Include an override service for emergency or system-failure scenarios.
