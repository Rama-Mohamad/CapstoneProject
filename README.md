# Smart Automated Gate System (SE_EE Capstone Project)

##  Project Overview
Automated Gate Control System using Facial Recognition

##  Objectives
- Improve **security** by replacing manual ID checks with AI-based facial recognition.
- Reduce **traffic congestion** at gate entrances.
- Provide **seamless and contactless access** for authorized vehicles and individuals.



## Expected Outcomes
- Faster and more reliable gate operations.  
- Increased safety and reduced need for manual guards.  
- Scalable system adaptable for universities, companies, and residential complexes.
